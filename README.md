## 🚀 What is GitFolio?
GitFolio is a modern web application designed to help developers create stunning, data-driven, and highly personalized GitHub Profile READMEs in seconds. With the power of AI (Google Gemini), GitFolio automatically analyzes your repositories, top languages, and tech stack to generate a unique, professional, and engaging profile tailored just for you.

## 🎯 Why We Built This
First impressions matter. Your GitHub profile is often your most important developer portfolio, and standing out is crucial. Building an impressive README from scratch can take hours of tweaking markdown, searching for the right badges, formatting tables, and crafting the perfect bio.

**GitFolio automates this entirely**, combining aesthetic themes with AI-generated storytelling to showcase your skills, coding streaks, and top repositories effortlessly. Less time formatting markdown, more time coding!

## ✨ What Can You Do With GitFolio?
- **AI-Powered Storytelling:** Uses Google Gemini to analyze your repos and job title to write a custom, engaging bio and "fun facts" about your coding habits.
- **Dynamic Stats & Trophies:** Embed beautiful GitHub stats, streak trophies, and activity graphs out of the box.
- **Customizable Aesthetics:** Choose from multiple color themes, dynamic header styles (waves, gradients), and toggleable sections.
- **Live Preview:** See your README update in real-time as you tweak styles and settings.
- **One-Click Markdown Export:** Simply copy the generated Markdown and paste it directly into your `username/username` repository!

## 🤖 Getting Your Free Gemini API Key
To use the "AI Magic" features of GitFolio (which analyzes your repos and writes a custom bio), you will need a Google Gemini API Key. It is completely free to get one!

### Steps to get your API Key:
1. Go to **Google AI Studio**: [https://aistudio.google.com/](https://aistudio.google.com/)
2. Sign in with your standard Google account.
3. Click on the **"Get API key"** button on the left sidebar.
4. Click on **"Create API key"** in a new or existing project.
5. Copy your newly generated API key!

### How to use it in GitFolio:
When you reach **Step 3 (AI Magic)** in the GitFolio wizard, paste this API key into the designated input field and click "Generate". 
> **Note:** We do **not** store your API key; it is only used locally in your browser to fetch your personalized content from Google.

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Framer Motion (for smooth micro-animations)
- **AI Engine:** Google Gemini API (`@google/genai`)
- **Markdown Processing:** `react-markdown`, `remark-gfm`, `rehype-raw`

## 🏃‍♂️ How to Run Locally

If you want to run GitFolio locally or contribute to the project:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/GitFolio.git
   cd GitFolio
   ```
2. Install dependencies (Node.js required):
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173` in your browser.
